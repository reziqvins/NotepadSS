================================================================================
  TEXTSHOT - NOTEPAD++ STYLE SCREENSHOT & WINDOWS 11 SNIPPING TOOL
  Versi Web Standalone - 100% Client-Side Pure Web (HTML5, CSS3, ES6 JS)
================================================================================

Aplikasi web modern untuk mengambil screenshot file teks (.txt, .log, .csv, dll)
dengan resolusi super tajam (Retina 2x, 3x Ultra HD), header tab Notepad++ mode
terang, fitur sembunyikan baris (Hide Lines) khas Notepad++, dan modal editor
anotasi interaktif bergaya Windows 11 Snipping Tool.

--------------------------------------------------------------------------------
1. FITUR-FITUR UTAMA:
--------------------------------------------------------------------------------
* TOMBOL "✂️ SNIPPING TOOL" DI TOOLBAR ATAS:
  - Tombol khusus di toolbar atas untuk membuka langsung Windows 11 Snipping Tool.
  - Jika ada baris yang dipilih: langsung mengambil screenshot baris tersebut dan
    membukanya di Snipping Tool.
  - Jika tidak ada baris yang dipilih: mengambil tampilan penuh dan membukanya.
  - Jika belum ada file yang dibuka: menyediakan kanvas gambar mandiri untuk anotasi.

* WINDOWS 11 SNIPPING TOOL & SECONDARY SHAPES BAR (SESUAI GAMBAR):
  - Secondary Floating Toolbar lengkap:
    * 🙂 Tombol Stiker / Emoji untuk menempelkan stiker reaksi ke screenshot
    * 🔲 Kotak Persegi (Rectangle)
    * ⭕ Lingkaran / Oval (Circle)
    * ➖ Garis Lurus (Line)
    * ↗ Panah Penunjuk (Arrow)
    * 🔵 Fill ˅ : Pemilih warna isian bentuk (30 warna Fluent + Transparan ⊘)
    * ⊘ Outline ˅ : Pemilih warna garis tepi bentuk
  - Pop-up Colors (30 Warna Windows 11 Fluent) + Slider Opacity berlatar catur!
  - Pulpen / Pen (P) dengan palet warna dan slider ketebalan.
  - Stabilo / Highlighter (H) transparan untuk menandai baris teks penting.
  - Penghapus / Eraser (E) untuk menghapus anotasi tanpa merusak screenshot asli.
  - Undo (Ctrl+Z) dan Redo (Ctrl+Y).
  - Tombol Salin Gambar (Ctrl+C), Simpan File (Ctrl+S), dan Edit in Paint.
  - Floating Zoom Bar & Ctrl + Mouse Wheel zoom.
  - Paste Gambar (Ctrl+V) langsung dari clipboard ke Snipping Tool.

* NOTEPAD++ HIDE LINES (Tampilan & Fungsi Asli Notepad++):
  - Indikator panah lipatan hijau (▲▼) di gutter nomor baris.
  - Garis pemisah hijau pembatas baris yang disembunyikan.
  - Tombol unhide pill interaktif untuk membuka kembali baris yang disembunyikan
    dengan 1 kali klik tanpa mereset posisi scroll layar.

* SCREENSHOT PANJANG PENUH (NO CUT / TANPA KEPOTONG):
  - Kalkulasi dinamis lebar teks dan karakter terpanjang.
  - Opsi ketajaman Retina (2x, 3x Ultra HD, 4x Print Quality).
  - Header tab Notepad++ mode terang dengan judul path file lengkap.

* SELEKSI BARIS PRESISI 100% (ANTI DRIFT):
  - Menggunakan arsitektur Unified Editor Row (.editor-row) yang menyatukan 
    nomor gutter dan teks, memastikan nomor baris yang diklik 100% sinkron 
    dan presisi bahkan untuk file laporan raksasa 7.700+ baris.

* SALIN LANGSUNG KE CLIPBOARD (COPY GAMBAR):
  - Blok baris yang Anda inginkan, lalu klik tombol "📋 Copy Gambar" atau 
    tekan shortcut keyboard "Ctrl + C" / "Ctrl + Shift + C".
  - Hasil screenshot langsung tersalin ke Clipboard Windows, tinggal tekan Ctrl+V
    pada WhatsApp, Telegram, Microsoft Word, Email, atau Slack!
  - Setelah salin selesai, file tetap terbuka pada posisi scroll yang sama dan
    blok seleksi otomatis dibersihkan.

* PENCARIAN TEKS CEPAT (Ctrl + F):
  - Temukan baris teks secara instan, navigasi Next / Previous (Enter / Shift+Enter),
    dan sorotan warna kuning pada teks yang cocok.

--------------------------------------------------------------------------------
2. CARA MENJALANKAN:
--------------------------------------------------------------------------------
Aplikasi ini 100% berbasis website (Pure Web Application):
- Cukup buka file "index.html" di browser favorit Anda (Google Chrome, Microsoft Edge,
  Mozilla Firefox, Opera, Brave, dll).
- Tidak memerlukan instalasi aplikasi desktop atau server khusus.
- Bekerja 100% offline di komputer Anda.

--------------------------------------------------------------------------------
3. DAFTAR SHORTCUT KEYBOARD:
--------------------------------------------------------------------------------
* Ctrl + O            : Buka file teks (.txt, .log, dll)
* Ctrl + F            : Buka fitur pencarian teks
* Ctrl + C            : Salin gambar baris terpilih ke Clipboard (buka Snipping Tool)
* Ctrl + Shift + C    : Salin gambar baris terpilih ke Clipboard
* Ctrl + V            : Tempel gambar dari clipboard ke Snipping Tool
* F5                  : Buka dialog opsi screenshot lengkap
* F6                  : Quick Full Screenshot (Simpan ke file)
* F7                  : Quick Selection Screenshot (Simpan baris terpilih ke file)
* Ctrl + H            : Buka / tutup panel Sembunyikan Baris (Hide Lines)
* Ctrl + Shift + H    : Sembunyikan baris-baris yang sedang dipilih
* Ctrl + Shift + U    : Tampilkan kembali semua baris tersembunyi
* Alt + Z             : Toggle Word Wrap
* Ctrl + A            : Pilih seluruh baris file
* Ctrl + + / Ctrl + - : Perbesar / perkecil ukuran font editor
* Esc                 : Tutup jendela modal / search / snipping tool
