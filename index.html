Screenshot file teks penuh tanpa terpotong ke samping atau ke bawah, tajam, dengan header tab Notepad++ mode terang dan fitur sembunyikan baris.

Fitur & Pintasan Cepat:
• Buka file: Klik tombol di atas, drag & drop file, atau tekan Ctrl + O
• Pencarian: Tekan Ctrl + F (bisa pilih atau sembunyikan hasil cari)
• Blok Baris: Klik nomor baris di kiri (tahan Shift untuk banyak baris)
• Copy Gambar (Tanpa Simpan): Tekan Ctrl + C atau klik tombol hijau 📋 Copy Gambar
• Simpan File Screenshot: Tekan F7 (terpilih) atau F6 (full)
• Sembunyikan baris: Klik ikon 👁 di samping nomor baris atau tekan Ctrl + Shift + H
